# TeachableMachine
teachable-machine-example

Project created with assistance from Google Gemini.
[Link to conversation](https://gemini.google.com/share/728436937720)

Design Decisions and Program Documentation
The style is modelled after the Wanna Be A Millionaire Game Show  
User only needs to press a button to start.
User can still try again for each question.
User can lock in answers, so they can properly choose the answer they want.

Limitations and Future Development
The user must possess a working microphone and mouse in order to use the website.
Accuracy may be limited due to limited training data. (Confusion between B and D)
